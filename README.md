# skunkpad

A workshop for small, useful things I build. Each folder is a self-contained project: the problem it solves, how it works, and a live demo where there is one.

I'm a product manager who builds. These are the builds.

## Projects

| Project | What it does | Live |
|---|---|---|
| [job-agent](./job-agent) | Pulls open roles from company hiring systems daily, scores each against my resume, and publishes a ranked feed. | _(link once deployed)_ |
| [meat-oracle](./meat-oracle) | Works out how much meat to buy for a cookout from who's coming and how hungry they are, then suggests what to cook. | [skunkpad-meat-oracle.vercel.app](https://skunkpad-meat-oracle.vercel.app/) |

## Why this exists

Specs and decks describe products. Working code shows you can ship one. This is the second kind.

More projects land here over time. Each one starts from a real itch and ends as something that runs on its own.
